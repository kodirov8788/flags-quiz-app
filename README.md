# Flags

An interactive world-flags quiz application with an additional management layer for content-driven gameplay.

**Live demo:** https://flags-day-project.vercel.app

## What This Project Shows
- Frontend state management for a user-facing quiz experience
- Router-based separation between user flows and admin flows
- UI composition with reusable components and third-party design helpers

## Why This Stack / Tooling
- **React** was chosen for building interactive quiz flows and reusable interface pieces.
- **React Router** makes it easy to separate public gameplay from administrative screens.
- **Flowbite + Tailwind CSS** accelerate consistent UI development for dashboards and forms.
- **Axios** supports API communication where flag/admin data needs to be loaded dynamically.

## Stack
- React 18
- React Router
- Tailwind CSS
- Flowbite
- Axios

## Key Features
- World flags quiz flow
- Admin/content management layer
- Responsive UI with reusable components
- Utility integrations such as toasts and carousels

## Getting Started
```bash
npm install
npm start
```
